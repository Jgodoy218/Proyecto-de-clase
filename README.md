# 🚀 Proyecto Personal - Rutas y Vistas en Laravel

Este proyecto es una aplicación web desarrollada con **Laravel** como parte de una práctica técnica. La aplicación muestra información de perfil estructurada en diferentes secciones a través de rutas y vistas independientes.

---

## 🛠️ Tecnologías Utilizadas

* **Framework:** Laravel
* **Lenguaje:** PHP
* **Plantillas:** Blade
* **Estilos:** CSS3
* **Control de Versiones:** Git & GitHub

---

## 📁 Estructura del Proyecto

* **Rutas (`routes/web.php`):** Manejo de navegación para la aplicación.
* **Vistas (`resources/views/`):**
* `perfil.blade.php` - Información personal del usuario.
* `intereses.blade.php` - Pasatiempos y gustos.
* `habilidades.blade.php` - Skills técnicas.
* `metas.blade.php` - Objetivos profesionales.
* **Estilos (`public/css/`):** Archivos CSS independientes creados para cada vista.

---

## 🔗 Rutas Disponibles

| Ruta | Descripción | Vista Asociada |
| :--- | :--- | :--- |
| `/` | Página de bienvenida predeterminada | `welcome.blade.php` |
| `/perfil` | Muestra la información personal | `perfil.blade.php` |
| `/perfil/intereses` | Muestra los pasatiempos y gustos | `intereses.blade.php` |
| `/perfil/habilidades` | Muestra las habilidades técnicas | `habilidades.blade.php` |
| `/perfil/metas` | Muestra los objetivos profesionales | `metas.blade.php` |
